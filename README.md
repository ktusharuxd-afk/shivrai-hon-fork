# SHIVRAI HON — Bitcoin Core Fork

Custom chainparams for SHIVRAI HON blockchain.

## For Miners
1. Clone Bitcoin Core v31.0
2. Copy patches/chainparams.cpp to src/kernel/
3. Copy patches/validation.cpp to src/
4. Build with CMake
5. Connect to operator's public address
